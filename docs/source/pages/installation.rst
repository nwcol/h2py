
============
Installation
============

For now, ``h2py`` must be installed from Github.

Using pip
=========

.. code-block:: bash

   pip install git+https://github.com/nwcol/h2py.git

Alternatively, we can install ``h2py`` by cloning the repository.

.. code-block:: bash

    git clone https://github.com/nwcol/h2py.git
    cd h2py/
    pip install -r requirements.txt
    pip install .

To edit the code, it is useful to use peform an editable install with
``pip install -e .``.
